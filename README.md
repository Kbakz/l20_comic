# L20 Comic

Um aplicativo Flutter para leitura e exploração de quadrinhos, oferecendo uma experiência intuitiva e agradável para os fãs de história em quadrinhos.

## 📱 Sobre o Projeto

L20 Comic é um aplicativo mobile desenvolvido em Flutter que permite aos usuários:
- Explorar uma biblioteca de quadrinhos
- Ler histórias em quadrinhos
- Gerenciar seus favoritos
- Acompanhar o progresso de leitura

## 🚀 Começando

### Pré-requisitos

- Flutter SDK (versão 3.0 ou superior)
- Dart (incluído no Flutter)
- Um emulador Android/iOS ou dispositivo físico

### Instalação

1. **Clone o repositório:**
```bash
git clone https://github.com/Kbakz/l20_comic.git
cd l20_comic
```

2. **Instale as dependências:**
```bash
flutter pub get
```

3. **Execute o aplicativo:**
```bash
flutter run
```
